# SOC Investigations

This directory contains documented security investigations conducted as part of the Threat Intelligence & Phishing Detection Lab.

## Purpose

The goal of each investigation is to demonstrate a structured SOC analyst workflow, from initial detection through threat intelligence enrichment, evidence analysis, and final disposition.

## Investigation Workflow

1. **Detection:** Identify a suspicious event or alert generated by Wazuh.
2. **Initial Triage:** Review the affected endpoint, timestamp, event details, and detection rule.
3. **Threat Intelligence Enrichment:** Investigate relevant indicators using publicly available threat intelligence sources.
4. **Evidence Analysis:** Correlate endpoint telemetry, detection results, and threat intelligence findings.
5. **Assessment:** Determine whether the activity is malicious, benign, or inconclusive based on available evidence.
6. **Disposition:** Document the investigation outcome and any recommended response actions.

## Investigation Report Structure

Each investigation report should include:

- Investigation title and date
- Investigation objective
- Alert or event summary
- Relevant indicators of compromise (IOCs)
- Threat intelligence findings
- Supporting evidence
- Analysis and conclusions
- Final disposition
- Recommended response or detection improvements
- Lessons learned

## Investigation Principles

- Use controlled, authorized lab activity.
- Distinguish confirmed evidence from assumptions.
- Do not classify an indicator as malicious solely because it appears in a threat intelligence source.
- Preserve relevant timestamps and event details.
- Document detection limitations and false positives.
- Never publish credentials, sensitive organizational information, or private user data.
