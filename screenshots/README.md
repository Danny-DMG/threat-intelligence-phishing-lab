# Lab Screenshots

This directory contains screenshots documenting the configuration, testing, and investigation activities performed in the Threat Intelligence & Phishing Detection Lab.

## Purpose

Screenshots provide supporting evidence for the technical work completed throughout the project.

They may be referenced in investigation reports, detection documentation, and the main project README.

## Planned Screenshot Categories

- **Lab Configuration:** Wazuh components, agent connectivity, and relevant monitoring settings.
- **Detection Testing:** Custom rule testing, matching events, and generated alerts.
- **Threat Intelligence Enrichment:** Indicator lookups and enrichment results from supported threat intelligence sources.
- **SOC Investigations:** Relevant event details, timelines, and investigation findings.
- **Validation:** Evidence demonstrating successful detection and end-to-end telemetry collection.

## Documentation Guidelines

- Use descriptive filenames that identify the activity being demonstrated.
- Include screenshots only when they provide meaningful supporting evidence.
- Reference screenshots from the relevant investigation or documentation file.
- Redact sensitive information before publishing.
- Avoid including credentials, API keys, personal information, or organizational data.
- Ensure screenshots accurately represent activities performed in the lab.

## Screenshot Status

Screenshots will be added as the lab is configured, tested, and documented.
